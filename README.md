# Epic Art Voyage

Preciso criar uma landing page para um concurso de arte da EpicSchool. Utilize como base o regulamento anexado e a estética precisa ser futurista em uma paleta de cores roxa com tema escuro e detalhes em azul e branco. Utilize como referência o site oficial: https://epicschool.com.br/
